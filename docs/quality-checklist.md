# Quality Checklist

Checks run on a prospect list before delivery.

**Targeting**
- [ ] Each company matches the agreed industry, location and size criteria
- [ ] Each contact's title matches the target roles
- [ ] Contacts appear to be current in the role (checked against the source date)

**Completeness**
- [ ] All required fields are filled, or the gap is explained in the notes
- [ ] Missing details are left blank, never guessed

**Accuracy**
- [ ] Email domain matches the company website
- [ ] Emails are verified, and each result is recorded with its date
- [ ] Phone numbers are labelled as sourced or checked

**Consistency**
- [ ] No duplicate companies or contacts (checked by email, and by name + company)
- [ ] Websites, locations and capitalization follow one format
- [ ] Column order and names match the client's CRM template

**Delivery**
- [ ] Source reference recorded for each record
- [ ] Summary of record counts and any exclusions included
