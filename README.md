# B2B Lead Research Sample

A demonstration of how a targeted B2B prospect list is structured, documented and quality-checked before delivery.

> **Synthetic data notice:** Every company, person, website and email in this repository is fictional. Domains use the reserved `.example` top-level domain, so none of them can receive mail. This is a demonstration project, not paid client work, and no record has been verified.

## Example brief

| Criteria | Sample value |
| --- | --- |
| Market | Software for logistics, supply chain, warehousing and trade compliance (including logistics analytics) |
| Geography | United States |
| Company size | 50–499 employees |
| Target roles | VP of Operations, VP of Sales, Head of Revenue Operations, Director of Sales Operations |
| Records | 15 (one decision-maker per company) |

## How a real list differs

In client work, the `email_status` and `source_reference` columns hold real values: the verification tool result and the date checked, and where each detail was found. In this sample they read **"Demo — not verified"** and **"Synthetic record — no real source"** on purpose, so that nothing here can be mistaken for real research evidence.

A verification result shows how an email checked on a given date. It does not guarantee the address will stay deliverable later.
